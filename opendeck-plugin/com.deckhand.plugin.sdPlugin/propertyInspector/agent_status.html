Default Input
One press does different things depending on the agent’s current status:
• Idle — start the agent
• Running — cancel the agent
• Awaiting Input — send Default Input to the agent
• Error — restart the agent

Default Input examples (used only when status is Awaiting Input):
• y or yes — approve a permission prompt
• n or no — decline
• Leave empty — send an empty reply (only if the agent accepts blank input)
Error Recovery
Auto-Retry
Max Retries
When the agent enters Error and Auto-Retry is on, the plugin restarts it automatically with linear backoff (5s, 10s, 15s, …) up to Max Retries. Leave Auto-Retry off if you want errors to stay visible until you press the button. A manual press on Error still restarts immediately and resets the retry counter.
