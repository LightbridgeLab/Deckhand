Sound
Sounds play through this Mac’s speakers, not the Stream Deck. Pick a different sound per button to tell sessions apart.
Default Input
One press does different things depending on the session’s current status:
• Idle — start (demo agents only; Claude/Cursor are already running)
• Running — cancel (local status only for Claude/Cursor)
• Awaiting Input — jump to that session so you can answer in the real UI
• Error — restart the agent

Deckhand cannot type Yes/No into Claude or Cursor. Default Input appears only for demo agents that actually accept text.
Error Recovery
Auto-Retry
Max Retries
When the agent enters Error and Auto-Retry is on, the plugin restarts it automatically with linear backoff (5s, 10s, 15s, …) up to Max Retries. Leave Auto-Retry off if you want errors to stay visible until you press the button. A manual press on Error still restarts immediately and resets the retry counter.
